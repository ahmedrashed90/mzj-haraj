Requested change
- Removed the publishing-period system from the active application flow.
- Daily ad quantity comes only from settings/haraj_publishing.dailyLimit.
- Every new assignment uses one global queue of all eligible active reps.
- Rep rotation continues across days instead of restarting each day.
- Contact block still contains all active reps and rotates the visible order per ad.
- Schedule and Word export no longer show publishing-period/time columns.

   7 days x 3 = 21 ads.
   Result: exactly 3 ads on each day, 21 total, all 14 reps reached before rotation repeats.

3) Contact rotation:
   Ad 1 starts with rep 1.
   Ad 2 starts with rep 2.
   The contact list continues rotating one position per ad.
