# MZJ Haraj Manager v1.4.1

نظام داخلي مستقل لإدارة جداول نشر إعلانات حراج وربطها بمخزون MZJ الحقيقي.

## الجديد في v1.4.1
- إظهار **فترة جدول النشر القادم** بشكل واضح داخل صفحة مخزون السيارات قبل فتح نافذة التجهيز.
- الفترة الحالية تُحسب تلقائيًا **من بكرة حتى الجمعة**، ويوم الجمعة تكون الفترة الجديدة **من السبت حتى الجمعة**.
- إلغاء تعديل تاريخ البداية والنهاية يدويًا من نافذة التجهيز حتى لا يتم إنشاء جدول على فترة خاطئة.
- إظهار عدد أيام النشر داخل بطاقة الفترة وفي نافذة الاعتماد.

- تحديث الهوية البصرية بالكامل لتطابق ألوان منصة MZJ: البني، النحاسي، الخلفيات الفاتحة، مع خط **Tajawal**.
- إضافة شعار MZJ إلى تسجيل الدخول والواجهة ونسخة جدول النشر المخصصة للحفظ PDF.
- التوزيع أصبح **حسب الفرع**:
  - كل فرع/حساب حراج له حد إعلانات حالي مستقل.
  - إعلانات الفرع توزع فقط على المناديب النشطين المرتبطين بنفس الفرع.
  - المندوب غير النشط/في إجازة لا يدخل في التوزيع.
  - عدد المناديب لا يرتبط بحد الإعلانات؛ الحد يمكن أن يزيد أو يقل كل أسبوع.
- تدوير متوازن بين مناديب نفس الفرع قدر الإمكان.
- دورة الأسبوع المعتمدة أصبحت **السبت إلى الجمعة**.
- عند تجهيز الخطة قبل أول جمعة، النظام يقترح تلقائيًا **من اليوم التالي إلى الجمعة**.
  - مثال 7 سبتمبر 2026: الخطة المقترحة 8 سبتمبر إلى 11 سبتمبر.
- عند إنشاء الخطة يوم الجمعة، يقترح النظام تلقائيًا **السبت التالي إلى الجمعة التالية**.
  - مثال الجمعة 11 سبتمبر 2026: 12 سبتمبر إلى 18 سبتمبر.
- حدود الفروع تقرأ وقت إنشاء الخطة؛ لذلك يمكن تعديل الحد يوم الجمعة قبل إنشاء الجدول الجديد.
- لا تتكرر سيارة في دورة التغطية طالما توجد سيارة أخرى لم تدخل خطة نشر بعد.

## جدول مدير الفرع

من صفحة **جدول النشر** يظهر لكل فرع زر **حفظ PDF للفرع**.

النسخة تحتوي على:
- الفترة.
- اسم الفرع.
- حد إعلانات الفرع.
- اليوم والتاريخ.
- المندوب.
- السيارة والبيان والموديل.
- خانة متابعة رابط الإعلان.
- سياسات النشر المختصرة.
- متابعة الرسائل والتعليقات.
- تنبيهات القيود أو ملاحظات حراج التي قد تؤثر على عدد الإعلانات.

الزر يفتح نسخة A4 جاهزة للطباعة؛ اختر **Save as PDF / حفظ كملف PDF** من نافذة الطباعة ثم أرسل الملف لمدير الفرع.

## إعداد الفروع والمناديب

من صفحة **الفروع والمناديب**:
1. أضف كل فرع/حساب حراج وحد الإعلانات الحالي.
2. اربط كل مندوب بفرعه.
3. اجعل حالة المندوب نشطًا فقط عندما يكون متاحًا للنشر.
4. في حالة الإجازة أوقف حالة المندوب مؤقتًا، وسيتم استبعاده من الجدول.

المناديب القديمة غير المرتبطين بفرع يظهرون بتنبيه ويجب اختيار فرعهم مرة واحدة.

## Firebase وVercel

- Firebase Authentication: تسجيل دخول المدير.
- Firestore: `haraj_accounts`, `agents`, `haraj_ads`.
- Vercel: الواجهة و`/api/stock`.
- `api/stock.ts` ما زال **قراءة فقط** من منصة MZJ ولم يتم تغيير منطقه في هذه النسخة.

متغيرات Vercel المطلوبة:

```text
MZJ_PLATFORM_BASE_URL=https://mzj-platform.vercel.app
MZJ_PLATFORM_IDENTIFIER=...
MZJ_PLATFORM_PASSWORD=...
```
