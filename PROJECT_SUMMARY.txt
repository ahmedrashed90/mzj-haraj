MZJ Haraj Manager v1.13.0 CLEAN

CORE RULES
- One actual Haraj account and one company daily limit.
- Daily publishing is configured through publishing periods.
- Every period has: name, start/end time, ads/day, ordered agentIds, active state.
- Active period ads/day total must equal the Haraj daily limit.
- Assignment follows each period rep order exactly; branch still comes from the assigned rep.
- Reps can be cash or installment.
- No vehicle repeats inside the same coverage cycle; after all eligible cars are covered, a new cycle starts.
- Cars without complete CompareKey are excluded from scheduling.
- Agency-location stock remains excluded.

V1.13.0 CONTACT ROTATION
- Every newly generated ad contains ALL agents whose active flag is enabled.
- Each contact snapshot contains agentId, name and phone.
- The contact list is rotated by one position for every next ad.
- Example: A/B/C -> B/C/A -> C/A/B -> repeat.
- Missing name or phone for any active agent blocks schedule creation.
- Assigned rep remains the publishing owner; contact rotation does not change assignment logic.

V1.13.0 AUTOMATIC WINDOW
- Automatic schedule starts on the same calendar day the button is pressed.
- Automatic schedule ends on the coming Friday, inclusive.
- Pressing the button on Friday creates a Friday-only window.
- Manual selected-row scheduling keeps its previous suggested-window behavior.

V1.13.0 WORD EXPORT
- PDF export was removed from the Schedule page.
- Each branch exports a real DOCX file generated in-browser.
- DOCX includes summary, day tables, assigned rep/type/vehicle/link status, and publishing policies.
- DOCX is RTL and does not depend on print dialogs or external packages.

AD COPY / COMPAREKEY
- Interior specs: CompareKey only.
- Exterior specs: CompareKey only.
- Safety specs: CompareKey only.
- Description contains all active rep names and phones in the per-ad rotated order.
- Description ends with tax-inclusive website price and the approved discount/gifts line.

FIRESTORE
- settings/haraj_publishing
- haraj_accounts
- agents (includes agentType)
- publishing_periods
- haraj_ads (includes contactAgentsSnapshot for new ads)

WORDPRESS BRIDGE
- MZJ Haraj Ad Data Bridge v1.1.0
- Read-only endpoint /wp-json/mzj-haraj/v1/cars

V1.13.0 DAILY LIMIT / PERIODS
- Daily limit is fixed per publishing day and is no longer required to equal the sum of publishing-period counts.
- Publishing periods are time/rep-order slots only.
- Automatic schedule quantity = dailyLimit * days in the active plan window minus already scheduled open ads in that window.
